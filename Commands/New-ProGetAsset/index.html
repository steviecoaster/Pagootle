New-ProGetAsset

SYNOPSIS

Transfers a file to a ProGet asset directory.

SYNTAX

New-ProGetAsset [-Path] <String> [-AssetDirectory] <String> [[-Folder] <String>] [[-AssetName] <String>]
 [[-ChunkSize] <UInt64>] [-Force] [-ForceMultipartUpload] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]

DESCRIPTION

Transfers a file to a ProGet asset directory. This function performs automatic chunking if the file is larger than a specified threshold.

EXAMPLES

EXAMPLE 1

New-ProGetAsset -AssetDirectory -Path C:\Files\Image.jpg
